# Мастерская — сбор продаж Яндекс Маркета (v34)
Основа: 6731b997beab24fc51dc8813460e0ac3bc9b31c5. Только чтение, по действующему зашифрованному подключению авторизованного владельца.
- Фактические продажи: POST /v2/reports/goods-realization/generate, GET /v2/reports/info/{reportId}, CSV ZIP. Доставленные, возвраты и невыкупы по датам и артикулам; доставлено минус возвращено по отчёту — разница, а не денежная выручка. Для FBS часть возвратов может требовать отдельного источника. Отсутствующие/неизвестные поля и неполный архив блокируют сохранение; NO_DATA отображается отдельно.
- Заказы: POST /v1/businesses/{businessId}/orders с фильтром магазина и дат оформления, постранично. Количество единиц и подтверждённые статусы единиц; неизвестные статусы не засчитываются в продажи. Не смешивать дату оформления с датой реализации.
- Результат сохраняется по подключению, версии, магазину и периоду; повторная выгрузка обновляет снимок. Проверки прав и версии перед запросами и сохранением. Повтор генерации в пределах 2 минут блокируется, незавершённый отчёт опрашивается без дублирования. В отчётах не сохраняются данные покупателей, ссылки на чеки, подписи временных ссылок. Удаление подключения удаляет локальные снимки этого подключения.
- Интерфейс: Интеграции → карточка Яндекс Маркета → Продажи и количество товаров. Календарь Москвы. Сбор запускается владельцем, без ИИ и автоматических проводок; комиссия, выручка, сопоставление SKU с изделиями и регулярный фоновый импорт не включены.
- 23 серверных и 3 браузерных теста успешно на имитированных ответах. Реальный формат файла и полнота данных конкретного магазина должны быть подтверждены первым запуском из авторизованного кабинета. Токен не выводится и не извлекается вне штатной обработки.
