# Мастерская: разрешения помощника и поиск (v30)
Основа: 7869be44e3b613e31adc60ad8f5abc62a15bd791. Патч применяется к текущему дереву выпуска, не заменяет общий Harness.
- Поисковый план формируется из публичной части текущего сообщения. Обычные формулировки о ценах, наличии, продавцах и поставщиках поддержаны; конфиденциальный контекст не передаётся автоматически. Существующие ограничения relay, SSRF, бюджета, повторов и подтверждения источников сохранены.
- Настройки → Разрешения помощника → Запрашивать подтверждение (по умолчанию включено, настройка отдельна для каждой мастерской).
- Явное поручение сохранить обычную запись разрешает серверное проведение одной полной типизированной операции после проверки. При отключённом подтверждении обычные поручения создания/изменения также проводятся. Отзыв настройки до проведения отменяет автоматическое разрешение. Архивирование, списание, сторно и исторические исправления требуют конкретного подтверждения.
- Смешанный поиск и запись используют общие механизмы. Если требовался поиск, но подтверждённого источника нет, автоматическое проведение блокируется. Текст модели не является доказательством записи или разрешением.
- Старый черновик можно восстановить по прямому поручению сохранить. При необходимости перезаписи существующих данных нужна проверка. Рабочие записи владельца при тестировании не менялись.
- Сохранены гостевой режим, классификатор, текущий доменный выпуск и платёжная конфигурация. Octoport не изменён.
- Проверки: 25 серверных сценариев исходной сборки, браузерный сценарий переключателя, затем финальный регрессионный прогон после исправления отрицания поиска. Живой поиск DeepSeek HTTP 200; живая запись контрольной рецептуры 300 / 16 = 18,75 ₽ сохранена без интернет-запросов. Связка поиска и записи отдельно проверена на управляемых ответах провайдера.
