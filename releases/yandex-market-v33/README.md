# Мастерская — Яндекс Маркет (v33)
На основе действующего выпуска 2be1cf6. Подключение Яндекс Маркета в общей форме интеграций, отдельное от Octoport и Wordstat. Только API-ключ; рекомендуем all-methods:read-only.
Проверка: POST /v2/auth/token (только чтение информации о токене), GET /v2/campaigns с limit и pageToken. Права токена, businessId, campaignId, модель и доступность API магазинов. Ошибки, 429, повтор страницы и неполный ответ не считаются полной проверкой. Ключ только в Api-Key заголовке, не в URL или ответе интерфейса. Redirects отключены.
Существующее шифрование AES-GCM, границы мастерской, замена/удаление по версии, сброс метаданных при смене ключа. Миграция сохраняет старые идентификаторы, ciphertext, версии, результаты проверок. Проверка не меняет магазин и не проводит продажи.
17 серверных тестов, 2 браузерных теста: подтверждены новый адаптер, миграция, форма и прежние Ozon/WB/Telegram, гостевые шаблоны. Провайдер имитирован. Живая проверка после ввода ключа владельцем. Импорт продаж/финансов, сопоставление SKU и запись операций не включены. Авито не добавлен.
Документация API: https://yandex.ru/dev/market/partner-api/doc/ru/reference/auth/getAuthTokenInfo ; https://yandex.ru/dev/market/partner-api/doc/ru/reference/campaigns/getCampaigns
