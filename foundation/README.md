# Первый рабочий каркас Подмастерья — 26.11.2026

## Сборка
Используется исходный выпуск Octoport 0deecb2089b4f56b28e21c7cf8e494fb4a8e3770 и его проверенный DeepSeek Harness 0.2.2-rc.1. Репозиторий публичный: здесь размещены только новый код и скрипт подготовки; исходники Octoport, рабочие БД, ключи, сессии и материалы магазинов не публикуются. Для сборки нужен доступ к закреплённому исходному выпуску на сервере. Скрипт не перезаписывает существующую директорию, не копирует симлинки и прежние документы плагинов. Runtime на сервере используется только для запуска тестов, без изменения действующего окружения.

```bash
python3 foundation/prepare.py --source /opt/harness-prod/releases/0deecb2089b4f56b28e21c7cf8e494fb4a8e3770 --destination /opt/podmasterye/candidates/new/source
cd /opt/podmasterye/candidates/new/source/products/harness-platform
RT=/opt/harness-prod/runtime/attachments-06f257269dd3
env -i PATH=/usr/local/bin:/usr/bin:/bin HOME=/tmp LANG=C.UTF-8 HARNESS_TEST_PYTHON="$RT/venv/bin/python" HARNESS_NODE_MODULES="$RT/node_modules" "$RT/venv/bin/python" -m unittest -v tests.test_podmasterye_foundation
```

## Реализовано
- Изолированное приложение, штатная серверная авторизация и роли Octoport; сотрудник мастерской не добавляется.
- Исходные монеты, бонус, платные права, кошелёк, наценка, начисления админа, шлюз, резерв, списание, сверка. Сохранён серверный checkout ЮKassa, включая виджет, webhook, возврат и повтор. Для фискального чека используется подтверждённая почта аккаунта, не логин. Новая область cookies и собственный адрес возврата.
- Внутренние метаданные ресурсов под ответом только для админа, в том числе для истории; у пользователя есть собственный кошелёк.
- Новый минимальный кабинет: сводка, материалы, изделия и рецептуры, баланс, встроенный помощник. Статический каталог собственных инструментов MCP; пользовательские плагины не активируются и их маршруты отсутствуют. Часть неактивного исходного кода остаётся в закрытой копии для совместимости.
- Локальный пилот матрицы до вызова модели; прямое сохранение рецептуры или FAQ без монет и токенов. Свободное сообщение через реальный Harness может подготовить черновик через MCP; пользователь подтверждает форму. Детерминированный расчёт стоимости расхода. Изоляция аккаунтов и повтор по requestId.

## Граница готовности
Не полная приёмка продукта. Не проверены браузеры Chromium/Opera, реальные письма, реальные DeepSeek и ЮKassa, полный набор сценариев авторизации/монетизации, OpenRouter, интерфейс всех настроек и публичные калькуляторы. Не реализованы складские движения, производство, продажи, финансы, несколько мастерских и интеграции. Полная матрица, формулы и будущие функции из документации пока не покрыты кодом. Для запуска требуется отдельная конфигурация, домен и ключи; продовые реквизиты автоматически не заимствуются. До выпуска необходимы независимые тесты, проверка UI и безопасности. Не заявлять функциональный паритет с СУЧКОМ.
