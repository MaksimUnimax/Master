# Вложения и диалог v13

Каждый продукт имеет собственную копию обработчиков, процессы, очередь, native-chats.sqlite3, usage.jsonl, БД начислений и конфигурацию провайдера. 16 основных модулей обработки побайтно совпадают с закреплённым выпуском Octoport. Нет общего экземпляра сервиса обработки и нет общего файлового хранилища. Исходный Octoport не изменён.

Включены штатные маршруты chat_attachments, MediaJobs и maintenance. Оригинальные file_reader/file_worker, OCR, ASR, Parse, verified-vision, vision-helper, учёт единиц, кэш, согласование стоимости, ограничения и сверка неизвестных исходов не переписаны. Композиционный адаптер соединяет их с матрицей и собственным чатом мастерской. Идентификаторы вложений входят в неизменяемый запрос; история показывает файлы из native journal. При переходе от локальной матрицы к модели недостающие локальные пары реплик добавляются через штатный механизм событий Harness. У исторических локальных реплик, отсутствовавших в старом native journal, порядок относительно прежних модельных реплик может отличаться; существующие события не переписываются. Подтверждение хозяйственных операций сохранено.

Интерфейс: компактный textarea, рост до 124 CSS px, Enter отправляет, Shift+Enter переносит строку, IME не прерывается; штатная стоимость и черновики файлов через file-cost/file-drafts, адаптер выбора/вставки/перетаскивания. Микрофон использует исходный voice.js с изменением только DOM-адаптации, вставки текста в textarea и пространства имён. В гостевом режиме вложения и микрофон отсутствуют. Админ-расходы включают медиа-единицы по режимам и неизвестные исходы без повторного суммирования.

Приёмка: 16 прежних серверных тестов, 3 новых сценария файлов/контекста/медиа, 2 браузерных сценария; дополнительная сверка статистики. Используются тестовые ключи и локальные провайдерные имитаторы, реальные вызовы DeepSeek не проверялись. Живое разрешение микрофона/распознавание речи также не подтверждено; ASR проверен через реальную серверную цепочку на синтетическом аудиофайле. Для прокси требуется разрешить до 8 МиБ тела запроса и достаточный таймаут распознавания; ограничение 8 МиБ сохраняется в приложении.
