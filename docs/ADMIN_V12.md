# Администрирование v12

Масштаб корневого интерфейса 0.8, как в pinned Octoport appearance.css. Сохранена зелёная палитра кабинета. Высота рабочего экрана компенсирует масштаб. Админка использует исходные appearance.css и admin.css, общую боковую навигацию и отдельные маршруты: обзор, API-ключи, модели, Telegram, монеты, расходы ИИ, матрица, пользователи, посещения. Legacy /app/?section=admin перенаправляется на /admin. Доступ проверяется на сервере.

Использованы механизмы Octoport для баланса, интервала обновления, Telegram-оповещений, моделей, гостевой активности, статистики пользователей. Активен только DeepSeek. Нет каталога плагинов и удаления пользователей, которые не входили в архитектуру продукта. Настройки и расход относятся к собственной БД. Баланс внешнего аккаунта провайдера общий, если используется один ключ.

Посещения: перенесены запросы API отчётов Яндекс Метрики, выбор периода, карточки и таблицы. Номер собственного счётчика и токен проверяются перед атомарным сохранением в приватный metrika.json. Фильтры ограничены доменом Подмастерья. Счётчик Octoport не используется. Сбор посещений не включён: для этого требуется отдельно установить счётчик с согласием посетителей. Боевые ключи и внешние запросы не используются в проверках.
