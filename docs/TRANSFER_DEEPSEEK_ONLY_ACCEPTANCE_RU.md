# Мастерская — DeepSeek-only, повторная приёмка 28.11.2026

## Результат изменения области
По решению владельца из функционального переноса исключены OpenRouter, личный выбор провайдера/модели и генерация изображений. Единственный модельный контур — прямой DeepSeek через штатный gateway Harness. Ключ, поддерживаемые модели, модель по умолчанию, режим рассуждений, разрешения моделей, баланс, порог и уведомления находятся в административном контуре.

Удалены альтернативный маршрутизатор, его настройки и маршруты API, восстановление его запросов, инструмент создания иллюстраций, генератор и отдельные сценарии развёртывания. Старые настройки и переменные не активируют удалённый провайдер. Исходная история v31 сохранена отдельно. Исторические финансовые записи не удаляются и не перевязываются на новый провайдер: оставшиеся обозначения старых тарифов нужны исключительно для учёта и сверки.

Сохранены штатные возможности Мастерской: личный кабинет, учёт, калькуляторы, гостевой контур, контекст, потоковый вывод, остановка ответа, DeepSeek Search/Fetch, чтение изображений, OCR/ASR, чтение и создание/редактирование документов, таймер и отчёты, платежный и аналитический контуры. Встроенный таймер не требует установки плагинов.

## Выпуск
Отмена OpenRouter и иллюстраций больше не является блокером. Новые реальные платные вызовы DeepSeek, реальная доставка Telegram, боевой платёж, Метрика с отдельным счётчиком/токеном, утверждение политики необратимого удаления и закрытый Git remote не подтверждены этим прогоном. Домен/почта относятся к отдельной работе. На production параллельно выпущен v34 с продажами Яндекс Маркета; зафиксирован релиз 4ef0c87d691c2c85243b729958741b5151d8ee8e. Он не включён в данный кандидат и не должен быть затёрт. Мастерская и Octoport продолжают работать. Новая сборка не установлена. Полная релизная приёмка требует объединения с актуальным production и проверки оставшихся внешних условий и полной браузерной матрицы.

Закрытое полное дерево и доказательства хранятся на Alisa. Git bundle содержит полный исходный commit 853365e8cc29e1ecd808369006b47c333bd2fe74, его целостность проверена. Публичный репозиторий содержит только документацию, закрытые исходники не публиковались.
