# Подключения маркетплейсов и Telegram

Подмастерье использует контракт полей и read-only проверки Octoport: Ozon Seller (Client-Id + Api-Key), Ozon Performance (Client ID + Client Secret), WB (API-токен). Пары Ozon независимы; повторное сохранение пары не уничтожает вторую. Связь проверяется явной кнопкой. Ключи хранятся в AES-GCM, отдельный ключ шифрования с правами 0600 в каталоге состояния Подмастерья; AAD привязывает ciphertext к мастерской, ID подключения и провайдеру. API возвращает только наличие полей, версии и результаты проверки, без значений. Удаление и ротация защищены проверкой версии. Нет автоматического импорта заказов и финансов из маркетплейсов: отдельный адаптер синхронизации ещё не подключён. Существующий push API своих магазинов не изменён.

Telegram: перенесены штатные consent/connect/complete/disconnect, проверка подписанного Telegram Login Widget и OIDC. В админке настраивается отдельная конфигурация бота; пользователи авторизуются из «Интеграции». Домен https://podmasterye.185-219-43-9.sslip.io, callback /telegram/return. Домен должен быть разрешён у Telegram. Не менять домен активного виджета Octoport: при одном разрешённом домене нужен отдельный бот или поддерживаемая регистрация второго origin. Настройки не копируются автоматически, токены не возвращаются. Состояние подтверждения и получатели в собственной БД. После подтверждения сервер проверяет доставку, затем сохраняет привязку. Тест/сводка и отключение доступны явно, без второго poller. Боевые подключения не проверены: тесты используют локальные имитаторы и синтетические ключи.

Резервное копирование: БД и секретные файлы состояния (market-connections.key, telegram.json, provider-keys) сохранять в закрытой резервной копии; восстановление ciphertext без ключа невозможно. Не помещать ключи в GitHub, сообщения или журналы.
