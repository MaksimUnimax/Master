## Историческая документация репозитория

# Подмастерье

Рабочее название проекта. Система управления малым производством с встроенным помощником. Старт исследований — 26.11.2026.

## Основная концепция
- Функциональный паритет с СУЧКОМ (https://suchok.su) по всем страницам и операциям, самостоятельный код и дизайн.
- ИИ-помощник — фундамент уже первой рабочей версии; SEO запускается параллельно, не откладывает ИИ. Отраслевые модули расширяют общую матрицу и исполнитель.
- Полноценный ручной интерфейс плюс встроенный помощник: открытие страниц, фильтры, формы, выделение показателей, чтение и изменение данных.
- Фильтр и матрица команд и справки обслуживают максимально возможную долю вопросов без ИИ, включая сложные объяснения устройства системы. DeepSeek только при необходимости. Все вычисления выполняются детерминированными скриптами.
- Ozon, WB, внешние магазины и розница через собственный API. Единый учёт сырья, производства, продаж и финансов.
- Основа — штатный DeepSeek Harness из Octoport (закреплённая версия, см. аудит). Переносим авторизацию, все роли Octoport, полную монетизацию (монеты, кошелёк, покупка, оплата, учёт и сверка), scoped MCP. Внутренняя детализация ресурсов под ответом доступна только администратору; пользователь видит свой баланс и списания как в Octoport. Пользовательская система плагинов и полноценный чат не нужны. Отдельной роли сотрудника мастерской нет.
